Airstream Weather Panel

Current conditions and the next ten hours, on a 640×180 strip built to live on a bulkhead. Plug the board in and press the button — there is no toolchain to install and no API key to sign up for.

This browser can't talk to serial devices. Use Chrome, Edge, or Opera on a desktop — Safari and Firefox don't support Web Serial. Serial access needs a secure page (https).

Takes about 30 seconds. Erases anything already on the board.

Then

  1. The panel comes up on a GET STARTED screen with a QR code, its network name and an eight-digit password.
  2. Scan the code with your phone's camera and tap the prompt to join, or join Airstream-Weather by hand with the password shown. A setup page opens by itself.
  3. Pick your Wi-Fi, enter the password, save. Leave the location fields blank unless you want to pin the panel to a fixed spot — by default it finds itself, and keeps doing so every time you move.
  4. The panel reconnects and the forecast lands within a few seconds. That's the whole install.

Using it

Tap an hourFull detail for that hour — feels-like, rain amount, gusts, humidity, dew point
Tap the temperatureSun arc, high and low, UV, pressure, visibility
Swipe rightOpen the System drawer; swipe left to put it away
Swipe downBrightness, refresh, and connection details
Press and holdFetch a new forecast now
BOOT button, shortStep the brightness down, wrapping back to Auto
BOOT button, doubleBack to Auto brightness
BOOT button, holdBlank the display; any touch wakes it

Seeing what the panel is doing

Press Install firmware again with the board connected. Once it is already running this firmware, the dialog offers Logs & Console instead of only reinstalling — that is the serial output, live, in the browser. Nothing to install.

It is the fastest way to answer "is it booting?". A healthy start prints a [panel] power mode line — the display controller reporting its own state back, so display ON, sleep out means it heard every command — then the touch controller it found, free heap and PSRAM, and the Wi-Fi state. Any line beginning [fatal] or [warn] is the panel telling you exactly what went wrong.

If the install button does nothing

Hold BOOT, tap RST, release BOOT, then press Install again. That forces the board into its download mode. On Linux you may also need to be in the dialout group.

Weather data from Open-Meteo. Source, wiring notes and the design brief are in the repository.
